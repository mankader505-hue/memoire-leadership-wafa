# موقع مذكرة القيادة الإدارية - مزوار وفاء

## النشر على Vercel

1. اذهب إلى https://vercel.com
2. سجّل بـ GitHub
3. اضغط New Project ← اختر repository
4. اضغط Deploy ← انتهى!

رابط موقعك: https://اسم-مشروعك.vercel.app

## التشغيل محلياً (اختياري)

```bash
npm install
npm run dev
```

ثم افتح http://localhost:3000
